\# FireSafe 360 – Smart Fire Detection \& Response Platform



\## About the Project

FireSafe 360 is a full-stack web application designed to manage fire incidents, analyze incident severity, and organize fire station information. It helps users record incidents and view their status through a centralized dashboard.



\## Features

\- Report fire incidents

\- Automatic incident severity analysis

\- View and track reported incidents

\- Manage fire station information

\- Generate incident response plans

\- Dashboard interface for incident management



\## Technologies Used

\- \*\*Frontend:\*\* React, Vite, HTML, CSS, JavaScript

\- \*\*Backend:\*\* Java, Spring Boot, Maven

\- \*\*Database:\*\* MySQL

\- \*\*API Communication:\*\* REST APIs, Axios

\- \*\*Version Control:\*\* Git and GitHub



\## Project Structure

\- `frontend/` – React user interface

\- `backend/` – Spring Boot REST API

\- MySQL database – Stores incident and fire station information



\## How to Run



\### 1. Start the Backend

Open CMD and navigate to the backend folder:



```cmd

cd backend

mvnw.cmd spring-boot:run

```



Configure your MySQL connection in `application.properties` before starting.



\### 2. Start the Frontend

Open a separate CMD window:



```cmd

cd frontend

npm install

npm run dev

```



Open the local URL shown by Vite in your browser.



\## Purpose

The project demonstrates Java full-stack development, database integration, REST API development, and incident management.



\## Note

This project is intended for educational and demonstration purposes. It does not replace official emergency services or certified fire detection systems.
